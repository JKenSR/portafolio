# Portafolio Multimedia Personal

Aplicación Web Multimedia desarrollada de forma autónoma para el curso **IF7102 - Multimedios** (Ciclo 2026), Universidad de Costa Rica, Sede Guanacaste.

## 🛠️ Framework Utilizado
* **Librería Core:** React.js (v18)
* **Entorno de Inicialización:** Create React App (CRA)

## 📋 Descripción del Proyecto
Este portafolio multimedia interactivo actúa como una carta de presentación técnica y profesional. La aplicación ha sido estructurada de forma modular mediante componentes desacoplados y reutilizables, consumiendo un almacén de datos dinámico en formato JSON mediante la API fetch nativa de JavaScript.
